Goals:
  • Collect and organize incident data from multiple sources.
  • Transform CSV data into a structured XML format.
  • Process and filter the XML using a custom Python script.
  • Generate statistics.
  • Store valid incidents in a clean JSON dataset.
Explanation

This project demonstrates how raw incident reports can be transformed into structured, reliable information. Using a workflow that includes CSV export, XML conversion, and Python‑based validation, the system filters incorrect entries, analyzes the data, and produces a final JSON file containing only valid incidents. The result is a streamlined process that turns unorganized input into clean, reusable, and meaningful data.
