
📌 Overview
This website was developed as part of the TA05 module project, with the goal of presenting a structured, interactive, and visually consistent portfolio of cybersecurity‑related assignments.
The site is coded using HTML, CSS, and JavaScript, with a focus on clean layout and clear navigation.

The project includes multiple pages, each dedicated to a specific task or demonstration, and a sidebar menu that allows users to move through the site easily.



📁 Website Structure
The website is organized into the following main sections:

1. Home Page
Introduces the portfolio and highlights the two most important projects.
It also displays the current date dynamically using JavaScript.

2. Project 1 — Incident Data Processing
Explains how raw incident reports are transformed into structured data using CSV, XML, Python validation, and JSON output.
Includes goals, explanations, and a 2×2 image grid showing the workflow.

3. Project 2 — Brute‑Force Login Detection System
Focuses on analyzing server logs to detect repeated failed login attempts.
Shows goals, explanation, and a visual representation of the detection process.

4. All Projects Page
Displays a grid of all cybersecurity‑related projects, each with an image, title, and short description.
This page acts as a full portfolio index.

5. Contact Form
A simple form where users can enter their name, email, phone number, and comments.
