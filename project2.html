Goals:
  • Collect and analyze server access logs.
  • Identify repeated failed login attempts and suspicious IP.
  • Detect brute‑force behavior using threshold‑based rules.
  • Visualize login failures and attack trends in a simple dashboard.
Explanation

This project focuses on detecting brute‑force login attempts by analyzing server access logs. A Python script processes raw log entries, extracts IP addresses, timestamps, and login results, and identifies suspicious behavior based on repeated failed attempts. The processed data is stored in JSON format and used to generate visual statistics that highlight attack patterns.
